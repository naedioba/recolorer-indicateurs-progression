User manual — Progress Indicator Recolorer

Overview

Progress Indicator Recolorer changes the colors of a series of progress images, from 0 to 100%, while keeping exactly the same size. It handles two types of images:

TypeParts recoloredExample
Progress circlesArc (percentage), rest of the circle, center text, backgroundThe 101 progress images of the Ender-3 V3 SE display
Progress barsFill (percentage), rest of the bar, border, backgroundA horizontal bar with square or rounded corners

In both cases, the program measures the shape of the indicator on the images themselves (thickness, rounding, where the arc or fill ends), then redraws it with the new colors while keeping the edges smooth.

The work takes four steps:

  1. Choose the image type when the program opens.
  2. Choose the image folder and the new colors, with a live preview.
  3. Recolor all the images at once.
  4. Put the images back into the display, for example with TJC TFT Tool for a tjc.tft file (available here: TJC TFT Tool).

What the program does not do: it does not change the shape of the indicator, the displayed percentage or the font. It only changes colors.

The interface is available in English and French.

Before you start

Always keep an untouched copy of the original images and, where relevant, of the original tjc.tft file: it is your safest way back.

  • Put the whole series, from 0 to 100%, in a folder that contains only these images.
  • Save the recolored images in a different folder from the originals.
  • This software is not affiliated with Creality or TJC. It is provided without any warranty: you use it at your own risk.

Installation

Two versions exist: a ready-to-use Windows program (.exe), and a Python version for other systems or for changing the code.

Windows version (.exe) — recommended

No installation: unzip the archive and double-click Recolorer progression.exe. Python is not required and the manual is built into the program. The archive also contains the LICENSE file.

On first launch, Windows SmartScreen may show "Windows protected your PC", because the program is not digitally signed. Click More info, then Run anyway.

Python version

  1. Download Python 3 from python.org and run the installer. Be sure to tick Add python.exe to PATH before clicking Install.
  2. Open the command prompt (Windows key, type cmd) and check the installation with python --version.
  3. Install the required libraries with python -m pip install pillow numpy.
  4. Put all the program files in one folder.

To open the interface, double-click recolorer_progression.py, or type python recolorer_progression.py in the command prompt from the program folder. On Windows, type python, not python3.

Choosing the image type

When it opens, the program shows two cards: Progress circles and Progress bars. Click the one that matches your images.

The ◀ Change type button, at the top right of the work screen, takes you back to this choice at any time. Folders and colors are then reset.

Choosing colors and recoloring

  1. Under Input, click Browse… and choose the folder of the series. The program analyzes the series for a few seconds, then shows how many images were found and the preview.
  2. The Output folder is suggested automatically (folder name followed by _recolored). You can choose another one.
  3. For each part, pick a color: click the swatch, click Choose…, or type a code such as #00FF00 and press Enter.
  4. Check the result in the preview, with ◀ ▶, on several percentages: 0%, 1%, 50%, 99% and 100%.
  5. Click the green Recolor all images button. A message then shows how many images were recolored and where they are.

Recolored images keep their name, format and size; JPGs are saved at high quality. If the output folder is the same as the input folder, the program asks for confirmation before replacing the originals.

Progress circles

The program handles square images: a centered ring on a plain background, whose arc starts at the top and runs clockwise. Other images in the folder are skipped, and the status message says so. The image size and ring thickness are measured automatically.

PartWhat it colorsCreality color
Arc (percentage)The part of the circle that grows with the percentageBlue gradient (Original)
Rest of the circleThe part of the circle not yet filled#101C20
Center textThe percentage written in the middle, if it is drawn on the image#FFC64A
BackgroundEverything else in the image#000808
  • Original Creality colors: the original colors of the Ender-3 V3 SE display, with the blue gradient on the arc. Applied to Creality's original images, they leave them strictly unchanged.
  • Green / beige: green arc #00FF00 and beige rest of the circle #E8D6B0.

Creality's blue gradient cannot be written as a single color code: to keep it, type Original in the arc field (the French word Origine is also accepted).

On the Ender-3 V3 SE, the progress images are numbers 2527 to 2627 in the tjc.tft file (2527 = 0%, 2627 = 100%), all 92 × 92 pixels. Extract them with TJC TFT Tool and copy these 101 files into a folder.

The program recognizes the parts of the circle by their position, not by their color: you can start again from recolored images and go back to Creality colors. The result is very close to the originals; to get the exact images back, start from the original images.

Progress bars

The program handles images at least twice as wide as they are tall: a horizontal bar in solid colors, with square or rounded corners (up to a "pill" shape), with or without a border, whose fill starts on the left and ends with a vertical edge. Other images in the folder are skipped.

PartWhat it colors
Fill (percentage)The part of the bar that grows with the percentage
Rest of the barThe part of the bar not yet filled
BorderThe outline around the bar (no effect if the bar has no border)
BackgroundThe outside of the bar, mostly visible in rounded corners
  • Original colors: the colors measured on the images of the input folder. Applied to those same images, they leave them strictly unchanged. This button first asks you to choose the folder.
  • Green / beige: green fill #00FF00, beige rest #E8D6B0, white border and black background.

The bar shape (margins, border thickness, corner rounding) is measured once on the most filled image of the series; the color of the rest of the bar, on the least filled one. If the folder holds images of several sizes, each size is analyzed separately.

Not supported: vertical bars, fills with a rounded end, strong gradients and text drawn inside the bar.

How the program reads the series

At 0% and close to 100%, the indicator may show a single color, and the number is not always drawn on the image. The program then works out the percentage from the image's place in the series:

  • if the file names carry numbers that run over 101 consecutive values, the first number is 0% and the last 100% (for example 0.png to 100.png, or 2527_92x92.png to 2627_92x92.png);
  • otherwise, if the folder holds exactly 101 images, the first one (in numeric order) is 0% and the last one 100%.

If the folder holds only part of the series, the program relies on the colors measured on the other images. The safest choice is still to keep the whole series in the same folder. Images are always listed in numeric order (2, 3… 10), not alphabetical order.

Putting the images back into the display

For the Ender-3 V3 SE display, use TJC TFT Tool (available here: TJC TFT Tool):

  1. With TJC TFT Tool, rebuild the tjc.tft file, using the program's output folder as the image folder.
  2. Check the resulting file with TJC TFT Tool.
  3. Install it on the printer following the display update procedure.

Solid colors usually compress better than gradients. Still, keep an eye on the remaining margin reported by TJC TFT Tool.

Command-line use

With the Python version, recoloring with the Green / beige colors also works without a window. The .exe version is used through its interface only.

CommandEffect
python recolorer_progression.pyOpens the graphical interface
python recolorer_progression.py circles folderRecolors the circles into folder_recolored
python recolorer_progression.py bars folder outputRecolors the bars into the output folder
python recolorer_progression.py folderGuesses the type: square images → circles, landscape images → bars

The French words cercles and barres are also accepted. Add --lang en or --lang fr to choose the message language. If a path contains spaces, put it in quotes.

Frequently asked questions

Will my colors look exactly the same on the printer's display?
Almost: the display shows 65,536 colors. The difference is a few levels per channel, invisible to the eye in most cases.

Can I use a gradient of my own color?
No. Each part takes a solid color, except the circle arc with Original, which keeps Creality's blue gradient.

Where is the chosen language stored?
In the recolorer_progression.json file, in the %APPDATA% folder on Windows, or in your home folder on other systems. You can safely delete it.
