Manuel utilisateur — Recolorer les indicateurs de progression

Présentation

Recolorer les indicateurs de progression change les couleurs d'une série d'images de progression, de 0 à 100 %, en gardant exactement leur taille. Il traite deux types d'images :

TypeParties recoloréesExemple
Cercles de progressionArc (pourcentage), reste du cercle, texte au milieu, fondLes 101 images de progression de l'écran de l'Ender-3 V3 SE
Barres de progressionRemplissage (pourcentage), reste de la barre, contour, fondUne barre horizontale, aux coins droits ou arrondis

Dans les deux cas, le logiciel mesure la forme de l'indicateur sur les images elles-mêmes (épaisseur, arrondis, fin de l'arc ou du remplissage), puis le redessine avec les nouvelles couleurs en gardant les bords adoucis.

Le travail se fait en quatre étapes :

  1. Choisir le type d'images à l'ouverture du logiciel.
  2. Choisir le dossier des images et les nouvelles couleurs, avec un aperçu en direct.
  3. Recolorer toutes les images en une fois.
  4. Remettre les images dans l'écran, par exemple avec TJC TFT Tool pour un fichier tjc.tft (à télécharger ici : TJC TFT Tool).

Ce que le logiciel ne fait pas : il ne modifie ni la forme de l'indicateur, ni le pourcentage affiché, ni la police. Il ne change que les couleurs.

L'interface est disponible en français et en anglais.

Avant de commencer

Conservez toujours une copie intacte des images d'origine et, le cas échéant, du fichier tjc.tft d'origine : c'est votre moyen le plus sûr de revenir en arrière.

  • Placez toute la série, de 0 à 100 %, dans un dossier qui ne contient que ces images.
  • Enregistrez les images recolorées dans un autre dossier que celui des originaux.
  • Ce logiciel n'est affilié ni à Creality, ni à TJC. Il est fourni sans aucune garantie : vous l'utilisez sous votre responsabilité.

Installation

Deux versions existent : un programme Windows prêt à l'emploi (.exe), et une version Python pour les autres systèmes ou pour modifier le code.

Version Windows (.exe) — recommandée

Aucune installation : décompressez l'archive et double-cliquez sur Recolorer progression.exe. Python n'est pas nécessaire et le manuel est intégré au programme. L'archive contient aussi le fichier LICENSE.

Au premier lancement, Windows SmartScreen peut afficher « Windows a protégé votre ordinateur », car le programme n'est pas signé numériquement. Cliquez sur Informations complémentaires, puis sur Exécuter quand même.

Version Python

  1. Téléchargez Python 3 depuis python.org et lancez l'installeur. Cochez impérativement la case Add python.exe to PATH avant de cliquer sur Install.
  2. Ouvrez l'invite de commandes (touche Windows, tapez cmd) et vérifiez l'installation avec python --version.
  3. Installez les bibliothèques nécessaires avec python -m pip install pillow numpy.
  4. Placez tous les fichiers du logiciel dans un même dossier.

Pour lancer l'interface, double-cliquez sur recolorer_progression.py, ou tapez python recolorer_progression.py dans l'invite de commandes, depuis le dossier du logiciel. Sous Windows, tapez python et non python3.

Choisir le type d'images

À l'ouverture, le logiciel affiche deux cartes : Cercles de progression et Barres de progression. Cliquez sur celle qui correspond à vos images.

Le bouton ◀ Changer de type, en haut à droite de l'écran de travail, ramène à ce choix à tout moment. Les dossiers et les couleurs sont alors remis à zéro.

Choisir les couleurs et recolorer

  1. Dans Entrée, cliquez sur Parcourir… et choisissez le dossier de la série. Le logiciel analyse la série quelques secondes, puis affiche le nombre d'images trouvées et l'aperçu.
  2. Le dossier de Sortie est proposé automatiquement (nom du dossier suivi de _recolore). Vous pouvez en choisir un autre.
  3. Pour chaque partie, choisissez une couleur : cliquez sur la pastille, cliquez sur Choisir…, ou tapez un code comme #00FF00 puis appuyez sur Entrée.
  4. Vérifiez le résultat dans l'aperçu, avec ◀ ▶, sur plusieurs pourcentages : 0 %, 1 %, 50 %, 99 % et 100 %.
  5. Cliquez sur le bouton vert Recolorer toutes les images. Un message indique ensuite le nombre d'images recolorées et le dossier où elles se trouvent.

Les images recolorées gardent leur nom, leur format et leur taille ; les JPG sont enregistrés en haute qualité. Si le dossier de sortie est le même que le dossier d'entrée, le logiciel demande confirmation avant de remplacer les originaux.

Cercles de progression

Le logiciel traite les images carrées : un anneau centré sur fond uni, dont l'arc part du haut et tourne dans le sens des aiguilles d'une montre. Les autres images du dossier sont ignorées, et le message d'état l'indique. La taille de l'image et l'épaisseur de l'anneau sont mesurées automatiquement.

PartieCe qu'elle coloreCouleur Creality
Arc (pourcentage)La partie du cercle qui avance avec le pourcentageDégradé bleu (Origine)
Reste du cercleLa partie du cercle pas encore remplie#101C20
Texte au milieuLe pourcentage écrit au centre, s'il est dessiné sur l'image#FFC64A
FondTout le reste de l'image#000808
  • Couleurs originales Creality : les couleurs d'origine de l'écran de l'Ender-3 V3 SE, avec le dégradé bleu de l'arc. Appliquées aux images d'origine de Creality, elles les laissent strictement identiques.
  • Vert / beige : arc vert #00FF00 et reste du cercle beige #E8D6B0.

Le dégradé bleu de Creality ne peut pas s'écrire avec un seul code couleur : pour le garder, tapez Origine dans le champ de l'arc (le mot anglais Original est aussi accepté).

Sur l'Ender-3 V3 SE, les images de progression sont les numéros 2527 à 2627 du fichier tjc.tft (2527 = 0 %, 2627 = 100 %), toutes en 92 × 92 pixels. Extrayez-les avec TJC TFT Tool et copiez ces 101 fichiers dans un dossier.

Le logiciel reconnaît les parties du cercle par leur position, et non par leur couleur : vous pouvez repartir d'images déjà recolorées et revenir aux couleurs Creality. Le résultat est très proche des originaux ; pour retrouver les images exactes, repartez des images d'origine.

Barres de progression

Le logiciel traite les images au moins deux fois plus larges que hautes : une barre horizontale en aplats de couleur, aux coins droits ou arrondis (jusqu'à la forme « pilule »), avec ou sans contour, dont le remplissage part de la gauche et se termine par un bord vertical. Les autres images du dossier sont ignorées.

PartieCe qu'elle colore
Remplissage (pourcentage)La partie de la barre qui avance avec le pourcentage
Reste de la barreLa partie de la barre pas encore remplie
ContourLa bordure autour de la barre (sans effet si la barre n'a pas de contour)
FondL'extérieur de la barre, visible surtout dans les coins arrondis
  • Couleurs d'origine : les couleurs mesurées sur les images du dossier d'entrée. Appliquées à ces mêmes images, elles les laissent strictement identiques. Ce bouton demande d'abord de choisir le dossier.
  • Vert / beige : remplissage vert #00FF00, reste beige #E8D6B0, contour blanc et fond noir.

La forme de la barre (marges, épaisseur du contour, arrondi des coins) est mesurée une fois sur l'image la plus remplie de la série ; la couleur du reste de la barre, sur la moins remplie. Si le dossier contient des images de plusieurs tailles, chaque taille est analysée séparément.

Ne sont pas pris en charge : les barres verticales, les remplissages à bout arrondi, les dégradés marqués et le texte dessiné dans la barre.

Comment le logiciel lit la série

À 0 % et près de 100 %, l'indicateur peut n'avoir qu'une seule couleur, et le chiffre n'est pas toujours dessiné sur l'image. Le logiciel déduit alors le pourcentage de la place de l'image dans la série :

  • si les noms des fichiers portent des numéros qui se suivent sur 101 valeurs, le premier numéro vaut 0 % et le dernier 100 % (par exemple 0.png à 100.png, ou 2527_92x92.png à 2627_92x92.png) ;
  • sinon, si le dossier contient exactement 101 images, la première (dans l'ordre des numéros) vaut 0 % et la dernière 100 %.

Si le dossier ne contient qu'une partie de la série, le logiciel s'appuie sur les couleurs mesurées sur les autres images. Le plus sûr reste de placer toute la série dans le même dossier. Les images sont toujours listées dans l'ordre des numéros (2, 3… 10), et non dans l'ordre alphabétique.

Remettre les images dans l'écran

Pour l'écran de l'Ender-3 V3 SE, utilisez TJC TFT Tool (à télécharger ici : TJC TFT Tool) :

  1. Avec TJC TFT Tool, reconstruisez le fichier tjc.tft en indiquant comme dossier des images le dossier de sortie du logiciel.
  2. Vérifiez le fichier produit avec TJC TFT Tool.
  3. Installez-le sur l'imprimante en suivant la procédure de mise à jour de l'écran.

Les couleurs unies se compressent généralement mieux que les dégradés. Surveillez tout de même la marge restante indiquée par TJC TFT Tool.

Utilisation en ligne de commande

Avec la version Python, la recoloration avec les couleurs Vert / beige est aussi possible sans fenêtre. La version .exe s'utilise uniquement avec son interface.

CommandeEffet
python recolorer_progression.pyOuvre l'interface graphique
python recolorer_progression.py cercles dossierRecolore les cercles dans dossier_recolore
python recolorer_progression.py barres dossier sortieRecolore les barres dans le dossier sortie
python recolorer_progression.py dossierDevine le type : images carrées → cercles, images en largeur → barres

Les mots anglais circles et bars sont aussi acceptés. Ajoutez --lang fr ou --lang en pour choisir la langue des messages. Si un chemin contient des espaces, mettez-le entre guillemets.

Questions fréquentes

Mes couleurs seront-elles exactement les mêmes sur l'écran de l'imprimante ?
Presque : l'écran affiche 65 536 couleurs. L'écart est de quelques niveaux par composante, invisible à l'œil dans la plupart des cas.

Puis-je mettre un dégradé de ma couleur ?
Non. Chaque partie prend une couleur unie, sauf l'arc des cercles avec Origine, qui garde le dégradé bleu de Creality.

Où est mémorisée la langue choisie ?
Dans le fichier recolorer_progression.json, dans le dossier %APPDATA% sous Windows, ou dans votre dossier personnel sur les autres systèmes. Vous pouvez le supprimer sans risque.
